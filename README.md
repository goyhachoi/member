# member — SNS 이미지 호스팅 저장소

《AI 10인 마케팅팀 이식 프로그램》 **수강생 케이스 테스트용** 저장소예요.
직원 4호(SNS 작가)가 만든 카드뉴스·썸네일 이미지를 여기에 올리고,
Buffer가 **발행 시점에** 그 이미지를 가져갑니다.

## 왜 GitHub인가요

Buffer는 이미지를 자기 서버에 복사해 두지 않고, **예약한 글이 발행되는 순간**에
URL로 가지러 와요. 그래서 그때까지 살아 있는 주소가 필요해요.

- 🚫 Replicate 주소(`replicate.delivery`)는 **약 1시간 뒤 만료**돼요 → 발행이 조용히 실패
- ✅ GitHub raw 주소는 만료가 없어요

## 폴더 구조

```
sns/
└── {image_slug}/          ← 콘텐츠 1건 = 폴더 1개
    ├── ig-01.png … ig-09.png    인스타 카드뉴스 (1080×1350)
    └── fb-01.png                페북 썸네일 (1536×1024)
```

`image_slug`는 원고 프론트매터에 적힌 **콘텐츠 단위 고유값**이에요.
주차로 묶지 않아요 — 묶으면 같은 주 두 번째 글이 첫 번째 이미지를 덮어써요.

## 올리는 법

직접 올리지 않아요. `Marketing_hub/04_sns/publish-images.ps1`이 해줘요.

```powershell
powershell -ExecutionPolicy Bypass -File "{HUB}\04_sns\publish-images.ps1" "{원고 파일명}"
```

저장소 주소는 스크립트가 아니라 **`04_sns/_github.txt`** 한 줄에서 읽어요.

## 주의

- 🔴 저장소는 **Public**이어야 해요. Private이면 Buffer가 이미지를 못 가져와요.
- 🔴 **이미 예약된 글의 이미지는 바꾸지 마세요.** 발행 내용이 사후에 바뀝니다.
  (스크립트가 기본으로 덮어쓰기를 막아요. 정말 바꿔야 하면 `-Force`)
